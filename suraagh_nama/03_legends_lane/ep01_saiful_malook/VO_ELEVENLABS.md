# Ep 1: ElevenLabs voice-over parts (v3.1 script)

**How to use:**
- Generate each part separately in ElevenLabs, with the voice shown for it.
- Keep the file names (`P01_NARRATOR.mp3` and so on) so the edit can place them in order.
- Model: **Eleven v3** (it supports Urdu and "..." pauses). If your plan only has Multilingual v2, test one part first.

**Pronunciation choices:**
- These words are written in English so they are pronounced correctly: Gazetteer, UNESCO, Hazara University, loudspeaker, landslide, glacier, glacial lake, record, Kunhar, Arakan, Khari Sharif.
- **سَر** (lake) has a zabar so it isn't read as "sir". **Listen to check it.**
- "حضرت سلیمان علیہ السلام" is written out in full so no symbol gets read aloud.

**The two Punjabi verse parts:** I recommend you record them yourself. TTS (text-to-speech) Punjabi in Shahmukhi often sounds wrong, and your own voice here adds a human touch.

## Voices
| Role | Voice and settings |
|---|---|
| NARRATOR | Dastango: a deep, warm, older male storyteller. Stability 45–55, Style 30–40, Speed 0.9 |
| LOUDSPEAKER | Same male voice, urgent and slightly distorted. Add a "loudspeaker / mosque PA" EQ in the edit |
| ASTROLOGER | Old male voice, slow and shaky. Stability 30, Style 50 |
| PRINCE | Young male voice, calm and firm. Stability 60 |
| FAIRY | Young female voice, frightened and breathy. Stability 35, Style 55 |
| DEMON | Very deep male voice. Pitch it down 3–4 semitones in the edit and add reverb |
| VERSE | Best recorded in Ahmad's own voice, in the style of reciting a poem. If using ElevenLabs, use the narrator voice slowed to 0.85 |
