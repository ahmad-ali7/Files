# Ep 1 audio: download guide for a local Claude session (YouTube Audio Library)

**For:** a Claude Code session on Ahmad's Mac with **Claude in Chrome**, signed in to YouTube.
**Where:** YouTube Studio → **Audio Library** (studio.youtube.com → left menu "Audio library"). It has two tabs: **Free music** and **Sound effects**.
**Save to:** `/Users/ahmadnawazali/Video Work/Saif ul malook lake/04_audio/` with the `music/` and `sfx/` subfolders shown below (create them).
**Then:** tell Ahmad it's done. The cloud session mixes everything under the voice-over.

## Rules
1. **Only use the YouTube Audio Library.** Its music is cleared for monetised YouTube videos.
2. Prefer tracks marked **"No attribution required"** (licence icon). If a track needs attribution, still OK, but copy its exact attribution text into `04_audio/CREDITS.md`.
3. **Avoid tracks with vocals or lyrics.** Instrumental only; the voice-over carries the words.
4. **Listen to the first 20–30 seconds** before choosing. It must feel **Pakistani or Persian, mysterious and night-time**, not upbeat, not EDM, not Western pop.
5. For each slot, pick the **best 1** and save the runner-up as `_alt`.
6. File names: exactly as below, keeping the original extension (.mp3).
7. Write `04_audio/LOG.md` with: slot, track title, artist, duration, licence (attribution yes/no), and why it was chosen.
