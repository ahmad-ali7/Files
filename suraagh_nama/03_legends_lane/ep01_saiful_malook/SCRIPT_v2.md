# Ep 1: Saiful Malook, script v2 (Ahmad's own voice)

**What changed from v1:**

1. **Opening.** It no longer starts on a bare date.
   - It opens with **you inside the scene**: night in Naran, the loudspeaker, people running.
   - Then it confirms **"this is not a story"**, which keeps it valid.
   - Then the childhood link (we all heard this story as kids, but not this part).
   - Then the 1907 warning about the fairies.
2. **Urdu, fixed with the same rules as the K2 script:**
   - The subject comes first, fully described, with the verb at the end.
   - Connecting words (لیکن، یعنی، یوں، پھر، اگرچہ، کیونکہ) carry the flow.
   - Clauses are joined with جو / جس / جہاں.
   - Short sentences appear only as deliberate punches.
   - There's no "میں آپ کو بتاؤں گا". It's "آئیے… دیکھتے ہیں" instead.
   - No sentence is left half-finished, and fewer cold dates appear.
3. **Everything links to everything:**
   - **The thread that returns:** "اور ناران ڈوب گیا".
   - **The irony:** the same book that tells of the "big city" calls Naran a handful of huts.
   - **A three-part link:** the stolen clothes → the mountain fairy belief → "their own fear" → the demon still exists.
   - **The ending closes the opening:** the 1907 warning about the fairies, the 2005 night, and "no hotel" against the tent villages.

**Unchanged:** every fact still maps to `DATASET.csv`, and there are no new claims.

**Length:** about 1,050 words, so **about 5 minutes** at your K2 pace. Cutting the ✂️ line saves about 10 seconds without breaking the links.
