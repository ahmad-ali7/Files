# Music: drop tracks here (YouTube Audio Library, "attribution not required")

Start each file name with its role. Anything after `__` is ignored. Example: `1_main_theme__Some Title.mp3`

| Role prefix | What it should sound like | Used for |
|---|---|---|
| `1_main_theme` | Slow, sparse solo piano, sad but tender | Story start and Tisar; the son born; the ending (restarts from the top each time) |
| `2_dark_drone` | Low ambient drone or pulse, no melody | The line arriving; the night and the fall; the drone footage; the three answers |
| `3_warm_strings` | Gentle, hopeful strings | Gabriel stays with him |
| `4_cold_bed` | Sparse, cold, unemotional ambient | Inquiry, price, promises, law |
| `5_build` | Slow build to an emotional peak and release | The summit swell; the record; the Sadpara recovery through "apne ghar wapas aa gaya" |

A role with no file gets a quiet synthesized interim pad, which is fine for review but not for upload.
