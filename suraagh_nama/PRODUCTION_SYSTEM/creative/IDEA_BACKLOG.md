# IDEA BACKLOG — episode pipeline

Where legend ideas live before they become episodes. Score each against the brand rubric; promote the top ones.
The cloud session keeps this current; it's the menu we pull the next episode from.

## Scoring rubric (1–5 each; the brand test in EXTENDING is a pass/fail gate first)
| Criterion | Question |
|---|---|
| **Place** | Is there a strong, filmable/satellite real place? |
| **Proof** | Is there checkable evidence (book, record, event, science)? |
| **Hook** | Is there a "you don't know the half of it" twist? |
| **Reach** | Will Urdu audiences search / recognise the name? |
| **Buildable** | Can the toolkit render it without a huge new lift? |

Total /25. Anything that fails the EXTENDING brand test (not place-anchored, or needs fabrication) is out regardless.
