# UPLOAD GUIDE (template) — YouTube Studio

For the local session (Chrome, signed in to the channel). Metadata comes from BUILD_SPEC §7.

## Rules
1. **Upload Unlisted (or Private) first. Do NOT publish Public without Ahmad's explicit OK.** Send him the link,
   wait. Publishing is public and hard to undo.
2. Upload the correct final master (verify it plays and is the latest cut, not an older one). Delete stale cuts
   from the folder first so the wrong file can't be picked.
3. Copy title/description/tags **exactly** from the spec (including the Urdu line, emojis, hashtags).

## Steps (studio.youtube.com)
1. **Create → Upload videos** → select the final master MP4.
2. Paste **Title** and **Description**.
3. Upload the **thumbnail** (1280×720 PNG).
4. **Audience:** not made for kids.
5. **Show more:** **Tags** (comma-separated), **Video language = Urdu**, **Category = Education**.
6. **Subtitles → Urdu (اردو) → upload the `.srt`**.
7. Confirm **chapters** appear (they come from the `00:00 …` timestamps in the description).
8. **Visibility = Unlisted.** Finish. Copy the link, send to Ahmad. Publish/schedule only on his word.

## After publish (optional, cloud can advise)
- First 48 h: watch CTR; A/B the title against the alternate from the spec; keep the winner.
- Hashtags live in the description, not the title. Pin a comment with the sources if useful.
